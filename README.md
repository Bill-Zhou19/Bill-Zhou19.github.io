# Jianming Zhou

Personal academic website: https://bill-zhou19.github.io/

The site uses plain HTML, CSS, and JavaScript. GitHub Pages publishes the `master` branch from the repository root. The `.nojekyll` file bypasses Jekyll for this static website.

Edit `index.html` for page content, `style.css` and `profile.css` for styles, and `app.js` for navigation and theme preference. Assets include the portrait, favicon, and public CV.

Content is based on the owner-provided CV. Section names and order follow the CV. Ongoing research, under-review papers, and undergraduate institution details are omitted from the public page and downloadable public CV at the owner's request.

Legacy Academic Pages template files are retained in the repository. The root `index.html` is the current homepage.
